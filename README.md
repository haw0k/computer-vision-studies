# Computer Vision — дослідження

Дослідження курсу [Computer Vision для інженерів](https://beetroot.academy/courses/online/course-computer-vision).

## Стек

- Python, OpenCV, PyTorch (CUDA), Ultralytics YOLO (YOLO26 / YOLOE)
- SAM (Segment Anything Model), ONNX Runtime (GPU)
- Roboflow для датасетов, формат Ultralytics YOLO
