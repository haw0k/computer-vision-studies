# Дослідження 01 — Що бачить комп'ютер

## Тема
Класичний Computer Vision: основи роботи з зображеннями в OpenCV.

## Завдання

### Основне завдання
1. Завантажте будь-яке кольорове фото (власне або з URL) та виконайте:
   - Відображення трьох каналів BGR окремо
   - Побудова гістограми по каналах та гістограми каналу V у HSV
   - Center crop та resize до 224×224, розрахунок розміру у MB для uint8 і float32
   - Підсумок: що розповіла гістограма про фото?

### Додаткове завдання
1. Вимкнення одного каналу `(img[:, :, 2] = 0)` та порівняння з оригіналом
2. Зміна контрасту: alpha=0.5 та alpha=2.0 в `convertScaleAbs`
3. Додавання шуму sigma=10, 25 та 50
4. Розрахунок пам'яті для 4K кадру (3840×2160×3) у uint8 та float32
