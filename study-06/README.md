# Дослідження 06 — Сегментація, кейси та дорожня карта

## Тема
Сегментація зображень, практичні кейси застосування Computer Vision та дорожня карта розвитку.

## Завдання

### Основне завдання
1. **Сегментація**: візьміть зображення з кількома об'єктами, запустіть YOLO-seg, обчисліть площу кожного знайденого об'єкта в пікселях та відобразіть маску найбільшого з них як overlay. Порівняйте bbox та маску для нього.

### Додаткова практика
1. Запустіть бенчмарк FP32 vs ONNX з ноутбука та зафіксуйте speedup на вашому середовищі
2. Спробуйте SAM з point prompt на одному зображенні (потрібно завантажити ваги ~375 MB)
3. Опишіть CV-задачу для свого домену за структурою з ноутбука: що детектувати, звідки дані, cloud чи edge, метрика успіху, основний ризик
