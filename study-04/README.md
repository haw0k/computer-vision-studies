# Дослідження 04 — Детекція об'єктів з YOLO26

## Тема
Детекція об'єктів на зображеннях за допомогою моделей YOLO26.

## Завдання

### Завдання А — Власні фото
Завантажте 2–3 зображення зі свого середовища (офіс, вулиця, природа). Спробуйте різні `conf` та порівняйте результати.

### Завдання Б — Aerial / Drone view
- Знайдіть aerial зображення (Google Maps, відкриті датасети)
- Запустіть `yolo26n` та `yolo26s` — порівняйте кількість детекцій
- **Очікуваний результат**: менше детекцій або неправильні класи — модель не навчена на aerial

### Завдання В — Open-vocabulary детекція (zero-shot)
1. **YOLO-World (на базі v8/v11)** — стабільне рішення, добре документоване
2. **YOLOE-26 (новіше, на базі YOLO26)** — швидший, NMS-free

### Додаткові завдання
1. **Conf sweep**: для conf ∈ [0.1, 0.25, 0.5, 0.75] побудуйте графік «кількість детекцій vs conf»
2. **Nano vs Small vs Medium**: порівняйте середній FPS, кількість детекцій та confidence
3. **Aerial**: запустіть yolo26n без tiling та з tile_predict(), запишіть приріст детекцій
4. **Відео**: запишіть 10-секундне відео з телефона та прогоніть з `save=True`
